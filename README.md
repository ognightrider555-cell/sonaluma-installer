# SonaLuma firmware installer

https://ognightrider555-cell.github.io/sonaluma-installer/

Installs the SonaLuma box (and hub) firmware or the Core2 remote firmware over USB from Chrome or Edge on a computer.
Settings on the device are kept unless "Start fresh" is ticked. To update a whole set, install on the hub only
(or box 1 without a hub): the other boxes copy it over the air.

Published from the SonaLuma repo with `SonaLuma9/Pyramids170/firmware/publish_installer.sh`.
