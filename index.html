SonaLumaFirmware installer

Use Chrome or Edge on a computer

This page installs over USB, which only Chrome and Edge on Windows, Mac or Linux can do. It won't work on a phone, Safari or Firefox.

1 · Pick what you're updating

2 · Install

Plug it into this computer with a USB-C data cable, click Install and choose its port.

Good to know

  • Updating a whole set: install on the hub only (or box 1 if the set has no hub). The other boxes copy it from there over the air.
  • Settings are kept: box number, hub switch, pairing, hotspot password and brightness stay as they are. Tick Start fresh only to reset a box completely; it then pairs again like a new box.
  • Box not found? Try another cable. If it still doesn't show, hold the small B or BOOT button on the box's board while plugging it in, then click Install again.
